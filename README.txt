Fleuré — ملف الموقع الجديد

الملف الأساسي الجاهز للنشر هو: index.html

الملف يستخدم إعدادات مشروع Supabase الحالي كما هي، ولا يتطلب إنشاء مشروع Supabase جديد.
يتضمن المتجر العربي RTL، عرض المنتجات من جدول products، الأقسام والبحث، الطلب عبر واتساب، ولوحة تحكم لإضافة/تعديل/إخفاء/حذف المنتجات ورفع الصور إلى products-images.

طريقة الرفع على GitHub:
1) افتح مستودع GitHub الخاص بموقع Fleuré.
2) اضغط Add file ثم Upload files.
3) ارفع ملف index.html نفسه من هذه الحزمة (لا ترفع ملف ZIP إلى المستودع بدلًا منه).
4) لو ظهرت رسالة استبدال الملف الموجود، اختر Commit changes لتحديثه.
5) من Settings ثم Pages، تأكد أن النشر من الفرع main ومن المجلد /(root)، ثم انتظر اكتمال النشر وافتح رابط الموقع.

مهم:
- لا ترفع أي service_role أو secret key إلى GitHub. الملف يستخدم publishable key فقط.
- لوحة التحكم تسجل الدخول بحساب Supabase Auth المخصص للبريد الموجود داخل الملف.
- لا تغيّر إعدادات Supabase الحالية أثناء رفع الملف.
